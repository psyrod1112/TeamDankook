# 개발하면서 고려할 것

코드 안의 `// TODO(N단계):` 주석과 짝을 이뤄요. 그 단계에 들어가기 전에 해당 칸을 읽고 정하고 시작하면 돼요.
정한 내용은 "결정" 칸에 적어 두세요.

## 공통
- mock → 실제 API로 바꿀 자리는 `lib/providers/providers.dart` 한 곳으로 모아 두기
- 화면마다 **로딩 중 / 에러 / 비어 있음** 상태를 따로 그리기 (지금 뼈대에는 없음)
- 권한 확인은 항상 서버에서. 앱의 버튼 숨김은 편의일 뿐 (portfolio XSS·IDOR 과제와 같은 원칙)
- 시간은 서버에 UTC로 저장하고, 화면에서 KST로 표시

## 3단계 · 실시간 채팅
- WebSocket 인증: 연결할 때 토큰을 어떻게 보낼지 (쿼리스트링은 로그에 남을 수 있음)

- 메시지 중복 방지: 앱이 만든 임시 id로 서버 응답과 맞추기 (portfolio의 order_id 멱등성과 같은 원리)
